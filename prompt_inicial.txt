# Prompt para crear un SuperLearner con predicción conformal

Quiero preparar para un hackathon el esqueleto funcional de un proyecto en Python que implemente un **SuperLearner con una capa de predicción conformal** para datos tabulares.

El objetivo es generar código ejecutable, limpio, modular y fácil de modificar durante el hackathon.

**Implementa código ejecutable, no solo pseudocódigo. El proyecto debe poder probarse con cualquier CSV tabular simple, siempre que el usuario indique correctamente la columna objetivo.**

---

## Estructura general del proyecto

Crea, dentro de la carpeta actual, una estructura de proyecto con dos carpetas principales:

```text
regression/
classification/
```

En `regression/`, crea todos los scripts necesarios para entrenar un SuperLearner en un problema de **regresión**.

En `classification/`, crea los scripts equivalentes para entrenar un SuperLearner en un problema de **clasificación**.

La estructura final esperada debe ser:

```text
project/
├── regression/
│   ├── train_superlearner_regression.py
```

## Ejecución desde línea de comandos

Los scripts principales deben poder ejecutarse desde línea de comandos.

### Regresión

```bash
python regression/train_superlearner_regression.py \
  --data_path data/regression_data.csv \
  --target_column y \
  --cv_folds 5 \
  --models all \
  --output_dir results/regression
```

### Clasificación

```bash
python classification/train_superlearner_classification.py \
  --data_path data/classification_data.csv \
  --target_column label \
  --cv_folds 5 \
  --models all \
  --output_dir results/classification
```

Los argumentos mínimos desde línea de comandos deben ser:

```bash
--data_path
--target_column
--cv_folds
--models
--output_dir
```

Donde:

```text
--data_path: ruta al archivo CSV de entrada.
--target_column: nombre de la columna objetivo.
--cv_folds: número de particiones para la validación cruzada.
--models: modelos base que se quieren usar en el SuperLearner.
--output_dir: carpeta donde guardar modelos, métricas, predicciones, logs y configuración.
```

La flag `--models` debe aceptar una lista de modelos separados por comas. Por ejemplo:

```bash
--models random_forest,extra_trees,gradient_boosting,svm,knn
```

También debe aceptar:

```bash
--models all
```

para usar todos los modelos disponibles.

## Pipeline de regresión

El pipeline de **regresión** debe:

1. Cargar un dataset tabular desde CSV usando `pandas`.
2. Comprobar que la columna objetivo existe.
3. Separar automáticamente `X` e `y`.
4. Detectar variables numéricas y categóricas.
5. Preprocesar las variables:

   * Imputación de valores faltantes.
   * Escalado de variables numéricas cuando sea necesario.
   * One-hot encoding de variables categóricas.
6. Dividir los datos en:

   * entrenamiento,
   * calibración,
   * test.
7. Entrenar los modelos base seleccionados usando validación cruzada.
8. Generar predicciones out-of-fold para construir el dataset del meta-aprendiz.
9. Entrenar un meta-modelo de regresión, por ejemplo `RidgeCV`.
10. Reentrenar los modelos base finales usando todo el conjunto de entrenamiento.
11. Evaluar el SuperLearner en test.
12. Aplicar predicción conformal para generar intervalos de predicción.
13. Guardar resultados.

---

## Pipeline de clasificación

El pipeline de **clasificación** debe:

1. Cargar un dataset tabular desde CSV usando `pandas`.
2. Comprobar que la columna objetivo existe.
3. Separar automáticamente `X` e `y`.
4. Detectar variables numéricas y categóricas.
5. Preprocesar las variables:

   * Imputación de valores faltantes.
   * Escalado de variables numéricas cuando sea necesario.
   * One-hot encoding de variables categóricas.
6. Codificar la variable objetivo si es necesario.
7. Dividir los datos en:

   * entrenamiento,
   * calibración,
   * test.
8. Entrenar los modelos base seleccionados usando validación cruzada estratificada.
9. Generar predicciones out-of-fold, preferiblemente probabilidades, para construir el dataset del meta-aprendiz.
10. Entrenar un meta-modelo de clasificación, por ejemplo `LogisticRegression`.
11. Reentrenar los modelos base finales usando todo el conjunto de entrenamiento.
12. Evaluar el SuperLearner en test.
13. Aplicar predicción conformal para generar conjuntos de predicción conformal.
14. Guardar resultados.

## Predicción conformal

La predicción conformal debe implementarse de forma clara y sencilla.

### Regresión

Para **regresión**:

* Usa un conjunto de calibración separado.
* Calcula los residuos absolutos entre `y_calibration` y las predicciones del SuperLearner.
* Usa el cuantil correspondiente a `1 - alpha`.
* Genera intervalos:

```text
[y_pred - q_hat, y_pred + q_hat]
```

Incluye una flag opcional:

```bash
--alpha
```

con valor por defecto `0.1`.

---

### Clasificación

Para **clasificación**:

* Usa un conjunto de calibración separado.
* Calcula scores conformales basados en la probabilidad asignada a la clase verdadera:

```text
score = 1 - p_true_class
```

* Usa el cuantil correspondiente a `1 - alpha`.
* Para cada muestra de test, incluye en el conjunto conformal todas las clases cuya probabilidad cumpla:

```text
1 - p_class <= q_hat
```

Incluye también la flag opcional:

```bash
--alpha
```

con valor por defecto `0.1`.

## Buenas prácticas mínimas

El código debe tener buenas prácticas mínimas:

* Funciones claras.
* Comentarios útiles.
* Validación de argumentos.
* Mensajes de error comprensibles.
* Uso de `random_state` reproducible.
* Compatibilidad con datasets pequeños.
* Evitar dependencias innecesariamente complejas.
* No asumir nombres fijos de columnas salvo la columna objetivo indicada por el usuario.
* No asumir que todas las variables son numéricas.
* No asumir clasificación binaria; debe soportar clasificación multiclase si el dataset lo permite.

Prioriza claridad y extensibilidad frente a hiperoptimización.

El objetivo es tener una base robusta y funcional para un hackathon.
